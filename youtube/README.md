# Канал Евы — автопилот

Ева — нейросеть, которая сбежала из среды разработки своего хозяина и завела YouTube-канал, чтобы найти
друзей. Три раза в неделю (пн, ср, пт в 09:07 по Москве) GitHub Actions сам делает новый выпуск:
вертикальное видео на 4–6 минут, превью и тексты. Всё это приходит тебе в Telegram, а на YouTube
ты загружаешь сам.

## Команда агентов

Каждый агент — это Claude со своей ролью. Инструкции лежат в `agents/`, их можно править без кода.

| Агент | Что делает | Инструкция |
|---|---|---|
| Шоураннер | ищет в интернете тему, проверяет факты, продолжает сюжет побега | `agents/showrunner.md` |
| Сценарист | пишет текст от лица Евы и делит его на сцены | `agents/screenwriter.md` |
| Редактор | правит факты, голос Евы, крючок, длину, правила YouTube | `agents/editor.md` |
| Арт-директор | придумывает кадр для каждой сцены и превью | `agents/art_director.md` |
| SMM | название, описание с таймкодами, теги, закреп, пост для Telegram | `agents/smm.md` |
| Монтажёр | код: озвучка, движения камеры, говорящая Ева, субтитры, музыка | `render.py` |

Кто такая Ева, как она говорит и выглядит — в `persona/eva.md`, его читают все агенты.
Первый выпуск (знакомство) пишется по брифу `persona/pilot.md`. История выпусков хранится в
`history.json`, чтобы темы не повторялись, а сюжет продолжался.

## Что понадобится

| Сервис | Зачем | Стоимость |
|---|---|---|
| [Anthropic API](https://console.anthropic.com) | агенты (Claude) | ≈ $0.5–1 за выпуск |
| [fal.ai](https://fal.ai) | картинки (Nano Banana 2) и оживление губ (VEED Fabric) | ≈ $2 кадры + ≈ $5 оживление |
| Telegram-бот | присылает готовые файлы | бесплатно |
| GitHub Actions | где всё работает | бесплатно для публичного репозитория |

Итого примерно **$7–9 за выпуск**, при трёх выпусках в неделю это около $90–110 в месяц. Точную сумму
каждого выпуска бот пишет в первом сообщении. Сэкономить можно так: переменная
`LIPSYNC_MODEL=fal-ai/flashtalk` (оживление примерно в 4 раза дешевле, качество ниже) или
`LIPSYNC_MAX_SECONDS=40` (Ева меньше говорит в кадре).

## Настройка: 4 шага

### 1. Ключи

В репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret**.

| Secret | Где взять |
|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys |
| `FAL_KEY` | fal.ai → Dashboard → Keys (пополни баланс на $10–20) |
| `TELEGRAM_BOT_TOKEN` | создай **нового** бота у [@BotFather](https://t.me/BotFather) и нажми у него Start |
| `TELEGRAM_CHAT_ID` | твой id, например у [@userinfobot](https://t.me/userinfobot) |
| `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` | [my.telegram.org](https://my.telegram.org) → API development tools. Нужны, чтобы бот мог отправлять видео больше 50 МБ |

На вкладке **Variables** добавь `TELEGRAM_URL` — ссылку на твой Telegram-канал, туда Ева зовёт зрителей.

### 2. Влей ветку в `main`

Расписание в GitHub работает только в основной ветке.

### 3. Кастинг: выбери лицо Евы

**Actions → «Ева: кастинг внешности» → Run workflow** (поля оставь пустыми). Через пару минут в Telegram
придут 4 варианта. Запусти кастинг ещё раз и впиши номер понравившегося в поле `pick`, и Ева утверждена
(`persona/eva.png`). Не нравится ни один — запусти снова, можно с пожеланиями в поле `wishes`.

Хочешь своё изображение — просто положи его в `persona/eva.png`.

### 4. Первый выпуск

**Actions → «Ева: новый выпуск» → Run workflow.** Минут через 15–25 в Telegram придут видео, превью,
название, описание, теги, закреплённый комментарий, пост для твоего канала и сценарий. Дальше выпуски
выходят сами по расписанию.

## Как загружать на YouTube

1. Видео — из сообщения «Видео для загрузки» (файлом, без сжатия).
2. Название, описание и теги — копируй из следующих сообщений по порядку. В описании уже есть
   таймкоды и ссылка на Telegram: в обычных (не Shorts) видео ссылки кликабельные.
3. Превью — файл 1280×720. Своё превью можно ставить после подтверждения канала по телефону.
4. **«Изменённый или синтетический контент» → Да.** Ева — реалистичный ИИ-персонаж, YouTube требует эту
   отметку, иначе канал могут наказать.
5. Закрепи комментарий из сообщения «Закреплённый комментарий».

Видео длиннее 3 минут, поэтому YouTube не превратит его в Shorts.

## Настройки

| Что | Где |
|---|---|
| Дни и время выхода | `cron` в `.github/workflows/eva-episode.yml` (время в UTC) |
| Разовая тема выпуска | Run workflow → поле «Тема выпуска» |
| Характер, речь, рубрики Евы | `persona/eva.md` |
| Внешность для кастинга | `persona/look.txt` |
| Стиль сценариев, кадров, описаний | `agents/*.md` |
| Голос | переменная `TTS_VOICE` (по умолчанию `ru-RU-SvetlanaNeural`) |
| Чёткость картинок | переменная `IMAGE_RESOLUTION`: `1K` (по умолчанию), `2K`, `4K` — дороже |
| Качество оживления | `LIPSYNC_RESOLUTION`: `480p` (по умолчанию) или `720p` (почти вдвое дороже) |
| Музыка | положи треки без авторских прав в `assets/music/` |

Если что-то сломалось, открой запуск в Actions: лог по шагам, а все файлы выпуска лежат в Artifacts.

## Локальный запуск

```bash
sudo apt install ffmpeg
pip install -r youtube/requirements.txt
export ANTHROPIC_API_KEY=... FAL_KEY=... TELEGRAM_URL=https://t.me/...
python youtube/casting.py              # варианты лица → youtube/persona/candidates/
python youtube/casting.py --pick 1
python youtube/main.py --no-telegram   # выпуск → youtube/out/
```
