# Как сделать 3D-Еву в VRoid Studio

VRoid Studio — бесплатная программа для Windows и Mac, в ней аниме-персонаж собирается ползунками,
примерно за 1–2 часа. Скачать: [vroid.com/studio](https://vroid.com/en/studio) (или в Steam).
Скелет и формы рта для гласных у модели будут готовые, их использует автопилот.

## Образ

Ориентир — описание в `eva.md`: девушка около 23 лет, модельная внешность, лёгкий «цифровой» намёк.

| Раздел | Что выставить |
|---|---|
| **Face** | взрослый тип лица (не детский): чуть уже подбородок, глаза среднего размера, аккуратный нос |
| **Eyes** | радужка светлая серо-голубая; добавь блик. В Eye Highlight можно чуть бирюзового свечения |
| **Eyebrows / Eyelashes** | тонкие, светлые, под цвет волос |
| **Hairstyle** | каре до подбородка (bob), чёлка набок. Цвет — серебристо-белый; в редакторе текстур кончики — лавандовые |
| **Face paint** | в текстуре кожи у левого виска тонкая бирюзовая линия, как дорожка микросхемы |
| **Body** | рост примерно 165 см, стройная, без преувеличенных пропорций (контент 13+) |
| **Outfit** | оверсайз-худи или парка графитового цвета. На груди маленькая надпись «EVA» (в текстуре одежды), низ — тёмные брюки или юбка |

Выражения лица оставь стандартными: автопилот использует встроенные формы «A, I, U, E, O», моргание и эмоции.

## Экспорт

1. Кнопка экспорта в правом верхнем углу → **Export VRM**.
2. Версия: **VRM 1.0**, если программа спросит. Подойдёт и VRM 0.0.
3. Настройки уменьшения полигонов и материалов можно оставить по умолчанию.
4. Заполни метаданные: автор — ты, разрешения на свой вкус.
5. Сохрани файл как **`eva.vrm`**.

## Как добавить в канал

Положи файл в репозиторий: `youtube/persona/eva.vrm`. Через сайт GitHub:
**youtube → persona → Add file → Upload files** (до 25 МБ; если больше — при экспорте уменьши
разрешение текстур до 1024).

Как только файл окажется в основной ветке:

- **Actions → «Ева: кастинг внешности» → Run workflow** — пришлёт в Telegram портрет 3D-Евы и 5 секунд,
  где она здоровается. Так видно, как она выглядит и как двигаются губы.
- Выпуски автоматически переключатся на 3D: во вступлении и финале говорит 3D-Ева, остальные кадры
  рисуются в её стиле, платное оживление губ больше не используется.

## Готовая модель вместо своей

На [VRoid Hub](https://hub.vroid.com) есть готовые модели. Бери только те, где в условиях разрешены
**коммерческое использование** и **изменение**, и помни: такая девушка может «работать» и на других каналах.
Своя модель уникальна — лучше сделать свою.
